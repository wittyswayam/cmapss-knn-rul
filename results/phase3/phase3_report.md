# Phase 3 results (generated)

Generated by `scripts/run_phase3.py report`. The official test files were not read by any Phase 3 step.

## Protocol

- Same grid for every subset (frozen before inspecting results): baseline ['none', 'causal'], normalisation ['global', 'regime'] (regime only where more than one regime is detected), window [10, 30, 50, 75], history ['adaptive', 'pad_first'], metric ['euclidean', 'manhattan'], weights ['uniform', 'distance'], k [5, 10, 20, 30, 50, 75, 100, 150].
- Engine-level CV (5 folds over tuning engines); 10 random cutoffs per engine from cycle 30; stress cutoffs [5, 10, 20]; window-level metrics use every 5th cycle.
- All `*_clip` metrics compare with the RUL clipped at 125; `*_raw` with the true RUL. NASA scores are the mean per prediction (see docs/EVALUATION_PROTOCOL.md).
- Development holdouts (exploratory): 20% of training engines per subset. Evaluations so far: {'FD002': 1, 'FD003': 1, 'FD004': 1} (FD001's holdout was evaluated repeatedly in Phase 2 and is not used here).

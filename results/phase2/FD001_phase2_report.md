# FD001 Phase 2 results (generated)

Generated by `scripts/make_phase2_report.py` from `results/phase2/`. The official test set was not used.

## Protocol

- 80 tuning engines (16779 rows) and 20 holdout engines (3852 rows), split by engine with seed 42.
- 5-fold CV over engines on the tuning set (validation engines per fold: [16, 16, 16, 16, 16]).
- Grid: 1920 configurations (sensor config x baseline x window x history strategy x metric x weighting x k).
- Engine-level evaluation: 10 random cutoffs per engine from cycle 30 on (800 points in tuning, 200 in holdout).
- Short-history stress points: cycles [5, 10, 20]. Window-level evaluation uses every cycle of every validation engine.
- `_clip` metrics compare with the RUL clipped at 125; `_raw` metrics compare with the true RUL. Selection criterion: engine-level RMSE vs clipped RUL (mean over folds).
